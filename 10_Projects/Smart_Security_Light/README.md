# Smart Security Light & Intrusion Alert System

## Status: DOCUMENTATION PLACEHOLDER (NO HISTORICAL IMPLEMENTATION FOUND)

### 1. Project Background
Identified as an application candidate for PIR motion detection, ambient light sensing, and automated lighting control.

### 2. Proposed Architecture & Requirements
- **Sensors**: Passive Infrared (PIR) sensor on EXTI line; LDR analog light sensor on ADC.
- **Actuators**: High-power LED / Relay-switched light.
- **Timing**: SysTick-driven auto-off timer after motion ceases.
